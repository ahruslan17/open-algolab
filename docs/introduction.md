# Introduction

OpenAlgoLab is a free and open-source project for learning algorithms visually, from first principles, and without memorizing templates.

## What Is This Project?

OpenAlgoLab is a local visual course for algorithms and problem-solving patterns.

It combines textbook-style explanations with step-by-step interactive traces, so learners can see not only the final code, but the movement of the algorithm:

```text
state -> decision -> state update -> why this step is correct
```

The project starts with interview-core patterns such as Sliding Window, Two Pointers, BFS, Binary Search, and Dynamic Programming. Over time, it is intended to grow into a broader algorithm reference.

## Why It Exists

Many algorithm resources show a finished solution too quickly. That can make learners memorize code without understanding why the algorithm works.

OpenAlgoLab takes the opposite route:

1. Idea.
2. State model.
3. Step-by-step trace.
4. Implementation.
5. Mistakes and variations.

The goal is to make algorithms feel inspectable rather than mysterious.

## How To Use It

Read the chapter first. Try to understand what state the algorithm keeps and why that state is enough.

Then use the interactive trace. Move step by step and ask:

- What changed?
- What stayed the same?
- What decision did the algorithm make?
- Why is that decision safe?

## Who Made It?

OpenAlgoLab was started by Ruslan as a free and open-source learning project.

The purpose is to create algorithm explanations that are understandable, visual, and useful for self-study.

The project is designed for contributors: new topics, translations, traces, examples, and better explanations should be easy to add without changing the whole app.

## Principles

- Free and open-source by default.
- Understand the concept before memorizing code.
- Every complete algorithm topic should have a trace.
- Every trace step should explain what happened and why.
- Learning content should be language-agnostic; implementations can be added in multiple languages.

## Main Promise

After a good OpenAlgoLab chapter, you should understand what the algorithm is doing at every step, not just remember which template to paste.
