# Announcement Drafts

Use these drafts when sharing OpenAlgoLab for early feedback.

## English

I started building OpenAlgoLab, a free open-source visual lab for learning algorithms through step-by-step traces instead of memorizing templates.

Current early MVP includes:

- Sliding Window
- Two Pointers
- interactive visualizer
- EN/RU content
- Python/C++ reference implementations
- static local setup, no backend or build step

It is early, but already usable locally and on GitHub Pages. Feedback and contributions are welcome:

Useful for self-study, interview practice, and explaining algorithm patterns visually.

https://github.com/ahruslan17/open-algolab
