# Practice Scope

OpenAlgoLab is a visual algorithms learning lab, not an online judge.

The project focuses on trace-first learning: explanations, visual state changes, pattern signals, hints, common mistakes, and curated practice links. It does not run, compile, grade, or store user submissions.

## What OpenAlgoLab Does Not Do

- It does not provide a compiler or interpreter.
- It does not accept code submissions.
- It does not run hidden tests or grade solutions.
- It does not require accounts, a backend, or a database.

Use external platforms such as [LeetCode](https://leetcode.com/) for submissions, official judging, and platform-specific constraints.

## What Practice Means Here

Practice in OpenAlgoLab is a curated learning path around each pattern. A practice item should help learners recognize when a pattern applies and what state or pointer movement to focus on.

OpenAlgoLab may provide:

- Guided explanations for selected problems.
- Step-by-step traces for completed modules.
- Pattern signals that help identify the right technique.
- Hints and focus notes for related problems.
- Curated links to external platforms for solving and submitting.

## External Problem Statements

When linking to external problems, link to the original page instead of copying the full statement. Short titles, difficulty, platform names, pattern notes, and focus hints are fine; full copyrighted statements should stay on the original platform.
