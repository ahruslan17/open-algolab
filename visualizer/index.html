Chapter 01 · Fixed-size Sliding Window

Maximum Sum Subarray of Size K

Learn how a fixed-size window moves across an array without recomputing every sum from scratch.

Concept

What problem are we solving?

Given an array and a number k, find the largest sum of any contiguous block with exactly k values.

Input nums = [2, 1, 5, 1, 3, 2], k = 3 Answer 9 from window [5, 1, 3]

Why sliding window?

Neighboring windows mostly share the same values. When the window moves one step, only one value leaves and one value enters, so the sum can be updated in constant time.

new_sum = old_sum - value_that_left + value_that_entered

State model

left
Start index of the current window.
right
End index of the current window.
window_sum
Sum of values currently inside the window.
best
Largest complete window sum seen so far.

Recognition rule

Use fixed-size sliding window when the problem asks for the best, count, or aggregate over every contiguous subarray or substring of exact length k.
